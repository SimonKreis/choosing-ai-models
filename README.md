# Choosing AI Models for Knowledge Work

**A decision framework**

**Simon Kreis & Claude.** Made with AI, mainly Claude (Anthropic), which contributed in part or in whole to the work. Simon Kreis is responsible for the result. From an original idea by Simon Kreis.

Updated October 2026.

A short essay on turning benchmarks into a choice. Model choice splits into two phases: a thinking partner for strategy and specifications, chosen for calibration and honesty (AA-PersonalityBench, AA-Omniscience), and an executor for agentic work, chosen on cost per task (AA-Briefcase, GDPval-AA, AutomationBench-AA). One model per phase rather than a router, and a system prompt that narrows the gap for cheaper models.
